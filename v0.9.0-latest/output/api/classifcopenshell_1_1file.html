class file¶

This class provides access to the entity instances in an IFC file The file takes ownership of instances added to this file and deletes them when the file is deleted.

Subclassed by hierarchy_helper< Schema >

Constructs an file object with the specified schema, file type, and file path.

Note

path is only used in RocksDB mode; an SPF file is in memory only until write() is called.

Parameters:

  • schema – Pointer to the schema definition to use. Defaults to the IFC4 schema if not specified.

  • type – The file type to use for the file. Defaults to FT_AUTODETECT.

  • path – The file system path to the IFC file. Defaults to an empty string.

  • logger – Logger used while creating the file.

Removes entity instance from file and unsets references.

Attention when running remove_entity inside a loop over a list of entities to be removed. This invalidates the iterator. A workaround is to reverse the loop: std::shared_ptr<aggregate_of_instance> entities = …; for (auto it = entities->end() - 1; it >= entities->begin(); &#8212;it) { ifcopenshell::IfcBaseClass *const inst = *it; model->remove_entity(inst); }
