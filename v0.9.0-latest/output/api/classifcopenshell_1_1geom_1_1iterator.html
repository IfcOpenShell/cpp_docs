Note

  • A true return value does not guarantee successful initialization of all elements. Some elements may have failed to initialize. Check had_error_processing_elements() to see whether there were errors during the initialization.

  • For non-concurrent iterators, a false return may occur if initialization of the first element fails, even if subsequent elements could be initialized successfully.
